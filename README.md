# Giovanni Anggasta, UI/UX Designer, Portfolio

Portfolio website for Giovanni Anggasta, UI/UX Designer at OttoDigital
Group in Jakarta, Indonesia. The design follows the Hang Nguyen Behance
portfolio (Portfolio UX/UI) reference: light off-white background, huge
lowercase "portfolio" hero, royal blue and bright yellow accents, thin
chapter numbers and bracket labels. All content matches Giovanni's CV,
and all site copy is in English.

## Case studies, in order

1. HokBen App
2. Taman Safari Quest — includes the interactive phone prototype, built
   from Gio's original Figma frames (440 × 956 px one-by-one exports in
   `public/images/safari-quest/`). Only the motion between screens is
   rebuilt; no UI is redrawn.
3. CHAMP: Food Ordering App — 10 slides from the Behance deck in
   `public/images/champ/`
4. CryptoX: Stablecoin App

More work: Travelies (Hotel Booking), Dashboard Business Portal,
Tokopedia flight booking.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Publish to GitHub Pages

This project is the contents of `giogioanggasta/giogioanggasta.github.io`.
From a clone of that repository, copy the files from this folder in, commit
and push to the `main` branch. The site is then live at
https://giogioanggasta.github.io/
